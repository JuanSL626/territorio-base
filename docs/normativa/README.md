# Investigación normativa interna

Este directorio contiene material de investigación metodológica para revisión
interna del equipo. **No forma parte del producto Territorio Base, no se
publica en su interfaz ni debe presentarse a usuarios como una funcionalidad
activa.**

Su contenido sirve para construir, contrastar y mantener un posible módulo
futuro. Solo se integrará a Territorio Base mediante una decisión explícita que
defina alcance, audiencia, modelo de acceso, revisión jurídica/editorial y
responsables de actualización.

## Puntos de entrada

1. [Mapa de actores de República Dominicana](01-mapa-actores-rd.md)
2. [Sistema de normativa, planificación y gestión](02-sistema-normativo-y-de-gestion-rd.md)
3. [Inventario priorizado de instrumentos](03-inventario-instrumentos-prioritarios-rd.md)

## Regla de trabajo

- Toda conclusión conserva su fuente, versión, fecha y límite de interpretación.
- Una fuente en investigación no equivale a una regla vigente o aplicable.
- Una geometría derivada no sustituye una delimitación oficial.
- Ningún contenido de este directorio se expone en el producto sin aprobación
  explícita del equipo.
