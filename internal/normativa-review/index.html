Normativa, planificación y gestión

Visor independiente para revisar actores, instrumentos y calidad de evidencia. No consulta datos de Territorio Base ni constituye una funcionalidad del producto.

Solo para revisión interna. No es dictamen legal, ruta de permisos ni determinación de edificabilidad. Cada entrada conserva qué se sabe y qué todavía debe verificarse.

Reglas del visor

  1. Una capa no sustituye el acto que la sostiene.
  2. Una intersección identifica una condición posible, no un permiso.
  3. La falta de información se muestra como vacío, nunca como ausencia de restricción.
  4. Las fuentes municipales se verifican municipio por municipio.
